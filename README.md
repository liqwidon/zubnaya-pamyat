# Зубная Память — прототип

Прототип сервиса для стоматологий: **напоминания о приёмах + возврат «спящих» пациентов**.

Статический сайт без бэкенда: HTML + CSS + чистый JavaScript. Все данные демо-кабинета хранятся в localStorage браузера посетителя — на сервер ничего не отправляется.

## Структура

```
├── index.html      — лендинг + демо-кабинет
├── css/style.css   — стили
├── js/app.js       — логика кабинета и калькулятора
└── README.md
```

## Что внутри

- **Лендинг**: герой с анимированным чатом-напоминанием, блок «как работает», тарифы.
- **Калькулятор экономики**: клиника вводит записи/чек/долю неявок — видит потери и потенциальную выгоду.
- **Демо-кабинет**: добавление пациентов (или загрузка примера базы), автоматическая классификация — кому напомнить о завтрашнем приёме, кого пора возвращать на профосмотр (>6 мес. без визита), предпросмотр сообщений.

## Запуск локально

Просто откройте `index.html` в браузере — сборка не требуется.

## Деплой на Netlify через GitHub

1. Создайте репозиторий на GitHub и загрузите эти файлы.
2. На netlify.com: **Add new site → Import an existing project → GitHub** → выберите репозиторий.
3. Build command — оставить пустым, Publish directory — `.` (корень).
4. Deploy. Сайт получит адрес вида `имя.netlify.app`.

## Что здесь заглушка (для будущей рабочей версии)

- Тексты сообщений — шаблоны в `js/app.js` (функции `reminderText` / `returnText`). В проде их заменит вызов LLM API (GigaChat / YandexGPT) через бэкенд.
- Кнопка «Отметить как отправленное» — в проде вместо неё реальная отправка через WhatsApp/Telegram-шлюз (Wazzup, Chat2Desk или Telegram Bot API).
- Хранение — в проде вместо localStorage база данных на сервере в РФ (152-ФЗ).
